# Modelos 3D usados na prévia

Os arquivos desta pasta vêm do Grab3D e são distribuídos pelo site sob CC0 1.0 (domínio público), inclusive para uso comercial, sem obrigação de atribuição. Os arquivos são incluídos localmente para evitar baixar modelos de terceiros a cada visita.

- `christmas-tree.glb` — árvore decorada, versão light. Fonte: https://grab3d.com/models/nature/christmas-tree/ — download: https://grab3d.com/dl/christmas-tree/christmas-tree-light.glb
- `christmas-wreath.glb` — guirlanda decorada. Fonte: https://grab3d.com/models/furniture/christmas-wreath/ — download: https://grab3d.com/dl/christmas-wreath/christmas-wreath.glb
- `snow-globe.glb` — globo de neve. Fonte: https://grab3d.com/models/props/snow-globe/ — download: https://grab3d.com/dl/snow-globe/snow-globe.glb
